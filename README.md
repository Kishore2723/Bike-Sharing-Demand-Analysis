# 🚲 Bike Sharing Demand Analysis

## 📌 Project Overview

This project analyzes bike-sharing demand data to identify patterns and factors affecting bike rentals.

The project uses Python, SQL, Excel, and Power BI to perform data cleaning, exploratory data analysis, querying, visualization, and dashboard development.

## 🎯 Objectives

- Analyze bike rental demand
- Identify hourly, daily, and seasonal patterns
- Study the impact of weather conditions on rentals
- Clean and prepare the dataset
- Perform analysis using Python and SQL
- Create Excel-based analysis
- Develop an interactive Power BI dashboard
- Generate meaningful business insights

## 🛠️ Tools & Technologies

- **Python** – Pandas, Matplotlib
- **SQL** – Data querying and analysis
- **Microsoft Excel** – Data analysis and visualization
- **Power BI** – Interactive dashboard
- **Jupyter Notebook** – Python analysis
